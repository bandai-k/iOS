# iOS モノレポ

複数の iOS アプリと、それらが共有する Swift Package を 1 つのリポジトリで管理します。

## ディレクトリ構成

```
Apps/                 アプリごとに 1 ディレクトリ（.xcodeproj はここに置く）
  UTCJST/             UTC と JST を表示するだけのアプリ
  SiteRecord/         看板付きで写真を撮る施工管理記録アプリ
  Sengiri/            野菜を千切りするタイムアタックゲーム
Packages/             アプリ間で共有する Swift Package
  ClockCore/          タイムゾーンの定義と時刻フォーマット（ロジック + テスト）
  SiteRecordCore/     看板の項目・保存・撮影日時フォーマット（ロジック + テスト）
  SengiriCore/        千切りゲームのルール・記録・タイム計測（ロジック + テスト）
docs/                 運用メモ
Makefile              ビルド / テストのショートカット
```

アプリ本体（SwiftUI の画面）は `Apps/` に、テストしたいロジックは `Packages/` に置く、
という分け方にしています。ロジックがパッケージ側にあると `swift test` だけで
シミュレータを起動せずに検証でき、2 本目以降のアプリからも再利用できます。

## 必要なもの

- Xcode 16 以降（プロジェクト形式が objectVersion 77 のため）
- iOS 17 以降のシミュレータまたは実機

## 使い方

Xcode で開く:

```sh
open Apps/UTCJST/UTCJST.xcodeproj
open Apps/SiteRecord/SiteRecord.xcodeproj
open Apps/Sengiri/Sengiri.xcodeproj
```

共有パッケージはローカルパッケージ参照としてプロジェクトに組み込まれているので、
別途 clone や resolve は不要です。編集するとそのままアプリ側に反映されます。

コマンドラインから:

```sh
make list                 # アプリと共有パッケージの一覧
make build APP=UTCJST     # シミュレータ向けにビルド
make test                 # 共有パッケージのテストを全部実行
```

## アプリ: UTCJST

現在時刻を UTC（協定世界時）と JST（日本標準時）の 2 つで並べて表示します。
表示するだけのアプリなので、設定画面もネットワーク通信もありません。

- 時刻は `HH:mm:ss`、日付は `yyyy-MM-dd (EEE)`、UTC からのオフセットも併記
- `TimelineView` で 0.5 秒ごとに更新（画面が見えていないときは停止する）
- ライト / ダークの両方に対応

## アプリ: SiteRecord（施工記録カメラ）

看板を写し込んだ工事記録写真を、できるだけ少ない操作で撮るためのアプリです。
起動するとすぐカメラが出て、シャッターを押すと合成・保存まで一息で終わります。

- 看板（工事名 / 工種 / 施工箇所 / 施工者 / 備考）は一度入力すれば端末に保存され、次回起動時も出たまま
- カメラのライブプレビューに看板と現在時刻を重ねて表示し、見たままの位置で写真にも焼き込む
- 焼き込む撮影日時はシャッターを切った瞬間の時刻（`yyyy/MM/dd HH:mm:ss`、24 時間表記）
- 撮影後は確認画面を挟まずカメラロールへ保存し、「保存しました」とだけ出して次の 1 枚に移れる
- 画面は縦固定。プレビューと焼き込みは同じ `BoardCard` を使うので見た目がずれない

施工前後の比較画像も作れます。カメラ画面右上のボタンから、カメラロールの写真を
「施工前」「施工後」に 1 枚ずつ選ぶと、見出し付きで 1 枚にまとめた画像になります。

- 横並び / 縦並びを切り替え可能。選んだ時点でプレビューが出て、保存でカメラロールへ
- 2 枚のセルは必ず同じ大きさにし、写真は縦横比を保ったままセル中央に配置
- 解像度が違う写真を並べても余白や見出しの比率は揃う。出力は長辺 4096px で頭打ち
- 配置の計算は `Packages/SiteRecordCore` 側にあり、単体テストで検証している

実機でのみ動作します（シミュレータにはカメラが無いため、起動しても案内表示になります）。
初回起動時にカメラと写真追加の許可を求めます。

なお、プレビューは画面いっぱいに切り取って表示（aspect fill）しているため、
実際に保存される写真はプレビューよりやや広い範囲が写ります。

## アプリ: Sengiri（千切り）

キャベツ・きゅうり・にんじんを、決めた回数だけ千切りするタイムアタックです。

- タップ 1 回で 1 カット。最初のタップで計測が始まり、目標回数のタップで止まる
- 千切り回数は野菜ごとに 10〜200 回の範囲で設定でき、次回起動時も残る
- ベストタイムは「野菜 × 回数」の組ごとに保存。回数を変えれば別の記録になる
- 野菜は画像ではなく SwiftUI の図形で描画。切った分だけ切れ目が増えていく
- 計測ロジック（`ChopSession`）は時刻を外から渡す作りなので、実時間を待たずにテストできる
