# App Store 提出用の素材

スクリーンショットの撮り方と、各アプリの掲載文案を置いています。

## スクリーンショットの撮影

広告バナーと ATT の確認ダイアログが写り込むと審査で問題になるため、
Speedometer と TimeZONE には撮影用の起動モードがあります。

```sh
xcrun simctl launch "iPhone 17 Pro Max" jp.nebulab.speedometer -screenshots
```

`-screenshots` を付けて起動すると、広告バナーを出さず、ATT の確認も求めません。

撮影の手順:

```sh
# 1. シミュレータを初期化する（前回の許可ダイアログが残っていると撮影を邪魔する）
xcrun simctl shutdown "iPhone 17 Pro Max"; xcrun simctl erase "iPhone 17 Pro Max"
xcrun simctl boot "iPhone 17 Pro Max"

# 2. インストールして状態を作る（例: 速度を出す）
xcrun simctl privacy "iPhone 17 Pro Max" grant location jp.nebulab.speedometer
xcrun simctl location "iPhone 17 Pro Max" start --speed=27.8 --interval=1 35.681,139.767 35.681,139.000

# 3. 撮影モードで起動して撮る
xcrun simctl launch "iPhone 17 Pro Max" jp.nebulab.speedometer -screenshots
xcrun simctl io "iPhone 17 Pro Max" screenshot speedometer-1.png
```

iPhone 17 Pro Max の画面は 1320x2868 で、App Store の 6.9 インチ用サイズそのままです。

SiteRecord はカメラを使うため、シミュレータでは撮影画面を再現できません。
実機で撮った画像を使ってください。

## 掲載文案

App Store Connect に貼る用の原稿です。名前は 30 文字、サブタイトルは 30 文字、
キーワードは 100 文字（カンマ区切り）が上限です。

### 施工記録カメラ（SiteRecord）

- **名前**: 施工記録カメラ
- **サブタイトル**: 看板付きの工事写真をすばやく
- **キーワード**: 工事写真,電子黒板,施工管理,建設,現場,黒板,写真,記録,土木,リフォーム
- **プロモーションテキスト**: 起動したらすぐカメラ。看板と撮影日時を写し込んだ工事記録写真が、シャッター 1 回で残せます。

**説明**

```
工事記録の写真を、できるだけ少ない操作で残すためのカメラです。

起動するとすぐカメラが出ます。シャッターを押すと、看板と撮影日時を写し込んだ
写真が、確認画面を挟まずそのまま写真アプリに保存されます。

■ 看板は一度入力するだけ
工事名・工種・施工箇所・施工者・備考を入力しておくと、次回起動時もそのまま出ます。
画面に写っている看板がそのまま写真に焼き込まれるので、仕上がりがずれません。

■ 撮影日時が写真に残る
シャッターを切った瞬間の日時を、24 時間表記で写し込みます。
写真そのものにも撮影日時・機種・撮影場所（位置情報を許可した場合）が記録されます。

■ 施工前後の比較画像
カメラロールから 2 枚選ぶだけで、見出し付きの比較画像を 1 枚にまとめられます。
横並びと縦並びを選べ、写真の解像度が違っても余白や見出しの比率は揃います。

■ 無料で使える範囲
撮影は 1 日 2 枚まで無料です。買い切りの「無制限アンロック」で枚数の制限が外れます。
看板の設定と比較画像の作成は、無料のまま制限なく使えます。
```

### スピードメーター（Speedometer）

- **名前**: スピードメーター
- **サブタイトル**: いまの速度を見るだけ
- **キーワード**: 速度,スピード,メーター,GPS,車,ドライブ,新幹線,電車,時速,速度計
- **プロモーションテキスト**: アナログとデジタル、好きな方で。車でも新幹線でも、いまの速度がすぐ分かります。

**説明**

```
いま何 km/h で移動しているかを表示します。それだけのアプリです。

■ 2 つの表示
アナログのメーターと、大きな数字のデジタル表示。左右のスワイプで切り替わり、
最後に見ていた方が次回も開きます。

■ 車でも新幹線でも
目盛りは 0〜180 km/h。速度が上がると 0〜360 km/h に自動で広がるので、
新幹線でも針が振り切れません。

■ 走行中に画面が消えない
表示している間は自動でスリープしません。

位置情報から速度を計算しています。トンネルなどで位置情報が途切れたときは、
古い速度を表示し続けずに「測定中」に戻ります。
```

### タイムZONE（TimeZONE）

- **名前**: タイムZONE
- **サブタイトル**: 日時をタイムゾーンで変換
- **キーワード**: 時差,タイムゾーン,世界時計,UTC,JST,時刻変換,海外,会議,出張,時計
- **プロモーションテキスト**: 「日本時間の月曜 10 時は、現地の何時？」を数タップで。

**説明**

```
日時をタイムゾーンの間で変換します。

■ 入力した日時を、並べたタイムゾーンすべてで見る
日時を選び、それがどのタイムゾーンの時刻かを指定すると、
他のタイムゾーンでの日時が同時に出ます。日をまたぐ場合は日付も分かります。

■ タイムゾーンは UTC からのずれで追加
地域名は 400 件以上あって選びにくいので、UTC からのずれ（37 種類）で選びます。
その帯の代表的な都市名も一緒に表示されるので、目的の場所を見つけやすくなっています。

■ 24 時間表記と AM / PM 表記
どちらでも表示できます。選んだ表記は次回も維持されます。

海外とのやり取りや、出張・旅行の予定を立てるときに。
```

## 提出時に必要な残りの素材

- スクリーンショット: iPhone 6.9 インチ（必須）。iPad 対応をうたう場合は 13 インチも必要
- App Store 用のアイコン 1024x1024（アセットカタログのものが使われる）
- 年齢制限（レーティング）の質問への回答
- 「App のプライバシー」の質問票（広告 SDK が集めるデータの申告を含む）
